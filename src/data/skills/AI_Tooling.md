As a founding member of the Developer Experience team that started in late 2025, I've been working hard to understand how engineers use AI agents in their day to day and how to increase efficiency and effectiveness with these tools while working in a large legacy codebase. Much of what we've wanted to fix up as part of the Developer Experience team for humans also helps in these areas. We still need faster and more comprehensive tests and tools and we need easily discoverable documentation to help new engineers and agents adhere to Bubble standards and understand domain concepts while also sticking to industry best practices. Most of 2026 so far has been full of working on all of these improvements that are even more important as AI tools can implement tickets so quickly.

In my own tasks I tend to use Claude as a pair programming buddy, working through a plan to implement each ticket and reviewing and testing code as we go. I still mostly prefer being in the loop for most tasks but have also experimented with letting a cloud agent fully implement a ticket and review it after. A big part of the Developer Experience team has involved making sure these flows are ready for others to be able to use easily. It's clear that project planning and well defined tickets are becoming more important as we let AI agents work on more features; this has always been a strong area for me and it is interesting to see this get more of a priority.
