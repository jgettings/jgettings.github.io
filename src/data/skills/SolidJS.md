SolidJS is a JSX based language like React and it is similar in many ways. The main difference is in how it reactively updates the UI more incrementally. On top of that, Bubble used SolidJS in an interesting way to hook into the legacy custom reactivity system that had been used before they adopted SolidJS.

I prefer working in React but mainly because of the ecosystem around it. Since React is more widely adopted there are many more libraries and tools available making it easier to work with. But beyond a few quirks, it does feel very similar to work with SolidJS. Even with less adoption in the industry, SolidJS is still popular enough that we can use it with things like Testing Library and Storybook, which is important to me. We are also using [Kobalte](https://kobalte.dev/), which is a SolidJS-specific UI component library.
